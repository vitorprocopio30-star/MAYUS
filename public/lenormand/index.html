Baraja Lenormand

Cómo funciona

El Lenormand es un sistema simbólico de 36 cartas. No predice hechos: describe dinámicas, y sirve para observar una situación desde otro ángulo.

  • 01 Formulas una pregunta concreta.
  • 02 El mazo se baraja y tú eliges tus cartas.
  • 03 Cada posición aporta una capa distinta de lectura.
  • 04 Las combinaciones muestran cómo se relacionan entre sí.
